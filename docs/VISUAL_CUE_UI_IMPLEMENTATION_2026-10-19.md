# Visual Cue：Emmaの身振りと音声連動UI（2026-10-19）

## 今回の到達点

ユーザーの追加依頼に従い、既存素材に加えてEmmaの7状態の身振りを制作し、実アプリに表示切替UIを追加しました。**新規7点・新しい英文割当は確認候補**です。既存素材の採用と区別し、ドラフトPR #107でレビューします。mainへのマージ・本体の公開は行いません。

- 基本14イラスト・10動作カテゴリに制作物があります。既存の静止22枚・動画21本の43点中、42点を採用済み、コップ1点を採用保留としています。
- Emmaは待機・にっこり・安心・ほめる・聞く・たずねる・誘うの7種類を追加。既存SVGの顔と配色を継承し、肩を支点に腕、首を支点に頭を動かします。全体を揺らすだけの動作ではありません。各状態に静止ポスターを付けています。追加指摘を受け、全身の構図は撤回し、通常表示と同じ顔の大きさ・位置、首・胸元を保つバストアップへ修正しました。待機・笑顔は小さなうなずき、他の状態は胸元・顔の横の手で表現します。
- 元の手の開閉・数える・wiggle・握る・tapの5 Cueは利用者指示で撤回したままです。他の意味の動画を割り当てて完成扱いにはしません。
- 起床の空のベッド＋太陽は意味未完成です。実行時は笑顔のEmmaへ置き換えます。くま・月は絵柄採用済みですが、3ポーズ原画の動画化は未完成のままです。

## コップの追加指摘への対応

静止ポスターの直線的な水面が縁に接して見えたため、簡易断面の初期量を95%から70%に下げ、内壁の奥に楕円の水面と曲線の反射を描きます。奥の内壁を残し、通常姿勢でも水面と縁の余白を見せています。傾けて縁に達した後の流出と、一方向の水量減少は維持します。

水面上端Y=200、奥の内壁1794画素、流出前の容器外の水0画素、流出時最大1017画素。他42点の採用時SHA256は一致します。43復号フレームを220pxで目視しました。**コップはユーザーの再確認待ちで、実行時カタログには含めません。**

## アプリでの使い方と動作

「設定 → 見た目 → 英語を話している間の表示」で「イラストと動き」を選びます。初期値は従来のEmmaです。動作のオン・オフを選べ、端末のreduced-motion設定も尊重します。

実際に音声が再生されたときだけ対応する表示を出し、音声終了・停止・エラー・タブ非表示で元のEmmaへ戻します。画像読込で音声を待たせません。未知の英文・読込失敗の場合も元のEmmaを表示します。表示部品の読込に失敗しても、音声・従来のEmmaは利用できます。

ホームと「遊ぶ」のEmma領域へ実装しました。履歴は従来どおり文字の一覧で、閉じると再生と表示を解除します。履歴に新たな絵の領域を追加していません。

採用済み音声は1応答につき1ファイルで、文ごとの確実な時刻情報はありません。3文は全体に合う表示を1つ出します。架空の均等な文境界や、音声が流れていない準備中の先行表示を使いません。

## 英文の対応と確認範囲

- 元の914セット（913ユニーク原文）と「遊ぶ」の178単文に対応を用意しました。実行時の完全一致カタログは合計1091件です。空白・大文字小文字・アポストロフィの表記だけを正規化し、実行時のキーワード分類は使いません。
- 3文セットは既存のdraft対応を引き継ぎ、疑問文・意味監査の注意対象には動作を断定する動画を避けます。洗う対象が手・足なら浴槽のシャワー動画へ置き換えません。
- 178単文は原文ごとに表示を明示しました。「Sip」「Tap」「Wiggle」など対象や動作が曖昧なものには保守的なEmmaの表示を使います。
- **元の意味確認済みは21セットです。893セットを承認済みへ昇格させていません。** 新規の単文対応と実行時対応も、利用者の意味確認はこれからです。1091件は対応表の件数で、意味の正解率や承認済み素材数ではありません。
- 元914セットとdraftの原文が変わった場合は生成で検知します。未知・変更された原文は従来Emmaへ戻るため、古い対応を無理に当てません。

## バストアップを維持する修正

「英語が出るといきなり全身になる」という指摘に対応しました。顔を既存素材の32%に縮小して全身を収める方式を撤回し、元の1024座標を512へ正確に半分にした顔・首・胸元を使います。アプリの身振りSVGにだけ掛かっていた320px上限も外し、通常のEmmaと同じ表示領域に合わせます。

待機と笑顔では手を出さず、軽いうなずきで表現。ほめるときは両手を頬の横へ、聞くときは片手を耳の下へ、誘うときは片手を顔の横へ上げます。腕は映像の途中から現れ、肩から動きます。新しい7点は引き続き採用確認候補です。

通常のEmmaから身振りへ切り替わっても親のゆっくりした揺れを継続し、上下位置のリセットを避けます。動作オフではその揺れも一時停止します。[通常表示](../assets/emma-gestures/qa/bust-idle.png)と[聞く身振り](../assets/emma-gestures/qa/bust-listen.png)を比較できます。
