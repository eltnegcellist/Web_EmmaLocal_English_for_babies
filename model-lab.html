Emma Model Lab

Emmaで使う軽量モデルと、より大きいモデルを同じ条件で比較する実験ページです。比較用なので本番Emmaの設定やモデルは変更しません。

1. Moonshine ASR 実用比較

Streaming / 育児語彙検証 v1：同じ録音で、現在の一括認識・真のStreaming・Tiny＋育児語彙・Small Streamingを比較します。本番EmmaのASR設定はまだ変更しません。

Streaming方式は録音を0.5秒ずつ実時間に合わせて流し、発話終了後に最終結果が出るまでの待ち時間も測ります。正解文を入れるとCER（文字誤り率）も計算します。

この欄はTiny＋育児語彙だけに使います。語彙を増やしてもモデルサイズや初回ダウンロード量は増えません。

まだ録音していません。

2. Kitten TTS 音質経路比較

音質経路比較 v2：同じKittenのFloat32出力を、A＝16bit PCM WAV、B＝32bit Float WAV、C＝AudioBuffer直接再生の3経路で聴き比べます。Aだけ悪ければ16bit量子化、Bも悪くCだけ良ければWAV/デコード経路、3つ同じならKitten生成時点の音質が主因です。

同じ英文・同じKiki音声で比較します。モデルは一つずつロードして生成後に解放するため、スマホでもメモリを使い過ぎにくい構成です。

1.00

Emma本番と同じKittenの speed パラメータをそのまま変更します。まず1.00を基準に、0.8 / 1.0 / 1.2などを聴き比べるのがおすすめです。

3. 他のローカルAI TTSを比較

同じ英文で耳比較：Kittenとは別系統のローカルAI音声を同じ文章で生成します。モデルは選んだものだけ読み込みます。

Kokoroは82Mモデルをブラウザ内で実行します。Supertonic 3は高音質ですが初回モデル取得が約380MBと重いため、必要なときだけ選んでください。Piperは軽量なローカルTTSの比較基準です。

Kokoro 82M / q8

Supertonic 3 / 44.1kHz

Piper / 軽量比較基準

英文は上の「読み上げる英文」を共通利用します。各エンジン固有の速度指定の意味が異なるため、この比較ではまず各エンジンの標準速度を使い、音質・声質を優先して聴き比べます。

4. 見るべきポイント

大きいモデルが常にEmma向きとは限りません。ASRは認識改善量と待ち時間、TTSは声の自然さと生成速度・初回DL量を一緒に比べると、モデルサイズを増やす価値が判断しやすくなります。

初回だけ各モデルをダウンロードします。モデルはブラウザのCache Storageに保存されるため、2回目以降は速くなる場合があります。
