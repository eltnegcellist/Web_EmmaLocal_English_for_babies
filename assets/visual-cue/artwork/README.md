## 原画・制作手段

実際に利用できる組込み`image_gen`でオリジナルの透過PNGを生成し、参照素材の平面的で丸みある絵本調に合わせました。CLI/APIフォールバックは使用していません。新規生成PNGは`sources/generated/`の11ファイル、正規化した編集原本は`sources/normalized/`、部品PNGは`parts/`に保存。生成指示と出自は[PROMPTS.md](PROMPTS.md)。実在商品の図版・ロゴ・キャラクターを複製していません。

初回のおもちゃは写実的なフェルト質感だったため不採用として再生成。おむつ初回は左右の留め具が画像端に達したため余白を再指定して再生成しました。使用しない出力は完成数に含めていません。

ZIPはSHA256検証後に`reference/`へそのまま展開。元ZIPは不変のバックアップとして残しています。`reference/`の19素材は比較資料であり配信用候補に混ぜません。分類は絵柄方向承認4、色修正の方向性承認1、未完成の追加候補5、hug再制作1、緑のおかゆ却下1、実験7。詳細は[inventory.csv](inventory.csv)。

## 検証と再現

Python 3.12以降、Pillow/numpy。今回のMac実行はPython 3.14.4 / Pillow 12.3.0 / numpy 2.5.1。ブラウザ検証はChrome 155.0.8059.80 / Playwright 1.62.1で実行。

```sh
python3 -m pip install -r scripts/visual-cue/requirements.txt
python3 scripts/verify-visual-cue-handoff.py
python3 scripts/visual-cue/build_artwork.py
python3 scripts/visual-cue/validate_artwork.py
python3 scripts/visual-cue/report_artwork.py
npm ci --ignore-scripts
npx playwright install chromium
# 別ターミナルで上記HTTPサーバーを起動
node scripts/visual-cue/capture_preview.mjs
```

再生成は保存済み原画から行うため画像生成サービスやAPIキーは不要。圧縮ライブラリの差でバイト列と容量は変わり得ます。制作は512×512、36フレーム×83ms＝2.988秒、原則12.05fps。WebPは同一フレームの持続時間をまとめるため、復号フレーム数は素材によって36より少なくなります。

自動検査はWebP全フレームの透過・512角・外周4pxの見切れ・背景面積、動画差分、220px縮小時の動作画素数、ループ継ぎ目、フラッシュにつながる平均輝度変化、指定した固定部位、全ポスターを検証。実測は`qa/validation.json`。器とスプーンのおかゆは中央値RGBで(252,239,210)/(252,236,203)、距離7.62。緑のおかゆは使用していません。

26/26素材が技術項目を通過。220pxで動画の変化画素は958〜16,515画素、継ぎ目差分/最大隣接差分は最大1.053。静止は全て150KB未満。動画は9/12本が400KB以下、手振り531,350B・キック619,486B・飲む402,222Bは超過。追加圧縮後も512pxで指・輪郭と質感を維持するため、現版は超過を記録して審査に出します。実端末で画質と負荷を判断し、更なる最適化は採用後の課題です。

ブラウザでは全画像の復号、3サイズ、全停止・再生、Reduced Motion、未完成絞り込み、390px幅の横はみ出し、58 Cue / 31コンセプトの表示を検証。JavaScriptエラー・404は0。`.github/workflows/visual-cue-artwork.yml`も同じ技術検証とキャプチャーを実行します。

## 審査と残課題

技術PASSは意味・人体・輪郭・乳児への理解しやすさの採用承認ではありません。特に手足の自然さ、ページの重なり、ミルク液面、おかゆのすくい方は実際に動かして確認が必要です。新規acceptedは0件を維持します。

残る制作は家族・おなか・抱っこ、手の各姿勢、着替え・拭く・げっぷ・起床、7 Emma状態の意味審査。おむつ試作も完成数から除外。人の確認が必要なのは、この一覧と動画の採用可否、人物描写を許容する抱っこ/おなかの構図、容量超過3本の端末確認です。アプリ接続や914英文への最終割当は別工程です。
